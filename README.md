# وب‌سایت پژوهشکده شبکه‌های برق — نسخه آماده GitHub Pages

این بسته یک وب‌سایت استاتیک مستقل، یک‌صفحه‌ای و آماده انتشار است و به نصب یا ساخت نرم‌افزاری نیاز ندارد.

طراحی پورتالی سرمه‌ای، قرمز و سفید بر اساس فایل طراحی ارسالی پیاده‌سازی شده است. تاریخ و ساعت زنده، جست‌وجوی داخلی، حالت روشن و تیره، منوی موبایل، نوار پیشرفت مطالعه و بخش پربازدیدترین‌ها نیز فعال هستند. رتبه‌بندی پربازدیدترین‌ها فقط از کلیک‌های همان مرورگر استفاده می‌کند و آمار ساختگی نمایش نمی‌دهد.

## انتشار در GitHub Pages

1. همه فایل‌ها و پوشه `assets` را در ریشه مخزن GitHub قرار دهید.
2. در مخزن به `Settings` سپس `Pages` بروید.
3. در بخش `Build and deployment`، گزینه `Deploy from a branch` را انتخاب کنید.
4. شاخه `main` و پوشه `/ (root)` را انتخاب و ذخیره کنید.

تمام پیوندها و تصاویر نسبی هستند؛ بنابراین سایت روی دامنه اصلی یا زیرمسیر یک مخزن GitHub Pages اجرا می‌شود.

## ساختار فایل‌ها

- `index.html`: تمام محتوای فارسی در یک صفحه
- `en.html`: نسخه انگلیسی یک‌صفحه‌ای
- `about.html`، `activities.html`، `projects.html`، `people.html` و `contact.html`: انتقال پیوندهای قدیمی به بخش مربوط در صفحه اصلی
- `404.html`: صفحه خطای GitHub Pages
- `assets/enri-logo.png`: لوگوی اصلی ارسالی پژوهشکده
- `assets/enri-building.png`: عکس ورودی ارسالی پژوهشکده
- `assets/illustrations`: تصاویر گرافیکی فایل طراحی ارسالی

## مبنای محتوایی

اطلاعات پژوهشکده از فایل‌های محتوایی قبلی استخراج شده است. در فرم رسمی جدیدتر، سال تأسیس ۱۴۰۰ ثبت شده و در پاورپوینت قدیمی‌تر سال ۱۳۹۴ آمده است؛ در وب‌سایت، فرم رسمی جدیدتر مبنا قرار گرفته و سال ۱۴۰۰ استفاده شده است.
